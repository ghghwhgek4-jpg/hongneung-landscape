홍능조경 V8 기반 V9 기능 업데이트

이번 버전은 V8 디자인/이미지를 유지하면서 기능과 구조를 보강했습니다.

1. 지역 홍보 문구 정리
- 메인/페이지 제목과 설명에서 '여주 소나무 판매' 중심 표현 제거
- 사업장 주소는 푸터/문의에 유지
- 네이버/Google 인증 메타데이터 유지
- LocalBusiness의 areaServed를 대한민국으로 정리

2. 메뉴/모바일
- PC/모바일 메뉴 클릭 정상화
- 모바일 햄버거 메뉴 열기/닫기
- 메뉴 선택 후 자동 닫힘
- 외부 클릭 시 메뉴 닫힘

3. 소나무 판매
- 전체/조경용/정원용/대형/반송·특수수형/묘목 카테고리
- 카테고리별 이미지 필터
- 이미지 클릭 확대
- 이전/다음 이미지
- 모바일 스와이프, ESC, 닫기 지원

4. 조경관리
- 전체/전지·전정/수목관리/정원관리/전원주택 조경 카테고리
- 카테고리별 이미지 필터 및 확대
- 중복 anchor 문제 수정

5. 시공사례/갤러리
- 전체/소나무/식재/관리/정원·조경 필터
- 갤러리 10개 이미지 구성
- 클릭 확대/이전/다음/모바일 스와이프

6. 이미지 참조 검사
- HTML에서 참조하는 로컬 이미지 누락 0개 확인

관리자 페이지
- 이번 V9에서는 공개 홈페이지 기능을 먼저 정상화했습니다.
- 다음 단계에서 Cloudflare R2 + D1 + 인증을 연결해 /admin에서 업로드/삭제/수정/카테고리/순서/공개 여부를 관리하는 구조로 확장할 수 있습니다.
