홍능조경 홈페이지 V2 업데이트

이번 버전은 조경업체 홈페이지의 전환 요소와 검색 노출을 강화한 전면 개편본입니다.

주요 변경:
1. 메인에서 전화/견적/이미지 3개 핵심 행동을 바로 노출
2. 소나무 판매/식재/전지·전정/정원관리/수목관리 서비스 구조 강화
3. 시공 이미지 전용 gallery.html 추가 + 카테고리 필터
4. FAQ 전용 faq.html 추가
5. 상담 프로세스 4단계 추가
6. 모바일 하단 전화/문자 CTA 강화
7. canonical / Open Graph / LocalBusiness 구조화 데이터 개선
8. sitemap.xml / robots.txt 추가
9. 모든 페이지 공통 메뉴 통일
10. 서비스 바로가기 앵커 연결
11. 현재 생성 이미지에는 '대표 이미지' 안내를 넣어 실제 시공사례와 혼동하지 않도록 처리

중요:
현재 이미지 중 AI로 만든 이미지는 실제 홍능조경의 시공 실적 사진이 아닙니다.
실제 현장 사진이 생기면 gallery.html의 이미지를 실제 사진으로 교체하는 것이 가장 중요합니다.
