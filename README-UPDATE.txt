# 홍능조경 홈페이지 업데이트 버전

기존 GitHub Pages/Cloudflare Pages 프로젝트의 디자인을 전면 개편한 버전입니다.

## 교체할 파일
- `index.html`
- `pine.html`
- `manage.html`
- `contact.html`
- `css/style.css`
- `js/main.js`

기존 `images` 폴더는 그대로 유지하세요. 현재 사이트에서 사용하는 `main.jpg`, `pine01.jpg`, `pine02.jpg`, `pine03.jpg`, `logo.png`, `favicon.png`를 그대로 참조합니다.

## 주요 변경
- 조경업체 포트폴리오형 디자인
- 모바일 최적화 및 하단 전화/문의 고정 버튼
- 소나무 판매/식재/전지·전정/정원관리/수목관리 서비스 확장
- 서비스·갤러리·상담 CTA 구성 개선
- SEO 메타정보 개선
- 전화 및 문자 상담 연결
- 네이버지도 위치 링크
- 기존 이미지 자산을 그대로 사용

## 적용 방법
GitHub 저장소에서 위 6개 파일을 교체하고 커밋하면 Cloudflare Pages가 GitHub 연동 상태에 따라 자동 배포됩니다.

주의: 주소와 전화번호는 현재 저장소에 등록된 정보(여주시 흥천면 신근리 923 / 010-7179-0316)를 기준으로 작성했습니다.
