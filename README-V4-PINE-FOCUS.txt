홍능조경 V4 - 소나무 판매 중심 개편

핵심 방향:
- 홍능조경의 주력 사업을 '조경용 소나무 판매'로 명확하게 표현
- 메인 H1 / title / description / keywords를 소나무 판매 중심으로 변경
- 메인 첫 번째 CTA를 소나무 판매 페이지로 연결
- 서비스 영역에서 소나무 판매를 가장 크게 노출
- 상담 프로세스를 소나무 구매 흐름에 맞게 변경
- FAQ에 소나무 판매 관련 핵심 질문 추가
- 검색엔진용 대표 이미지와 페이지 문구도 소나무 판매 중심으로 유지
- 기존 네이버/Google 인증 메타데이터는 그대로 보존

추천:
실제 판매 가능한 소나무 사진, 품종/수형, 대략적인 크기, 가격대 또는 '가격 문의' 기준을 확보하면 다음 업데이트에서 상품성이 크게 올라갑니다.
